# CivicVoice

CivicVoice is a comprehensive web-based grievance redressal system designed to facilitate transparent and efficient communication between citizens and the administration. The platform empowers citizens to register their concerns and enables officers to manage and resolve them effectively.

## 🚀 Features

### For Citizens
- **User-Friendly Dashboard**: Easy access to all services.
- **Register Grievances**: Submit complaints with detailed descriptions.
- **Track Status**: Monitor the progress of registered grievances (implied).

### For Administrators
- **Admin Dashboard**: Overview of system statistics and activities.
- **Officer Management**: Register new officers and manage existing ones.
- **Citizen Management**: View registered citizens.

### For Officers
- **Grievance Management**: View and address grievances assigned to their department.

## 🛠️ Technology Stack

- **Backend**: Java, Spring Framework, Hibernate ORM
- **Database**: MySQL
- **Frontend**: JSP, HTML, CSS
- **Build Tool**: Maven

## ⚙️ Setup & Installation

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/GAURANG022004/Civic-Voice.git
    ```
2.  **Configure Database**:
    -   Update the database credentials in the configuration file.
    -   Ensure MySQL is running and the database is created.
3.  **Build the project**:
    ```bash
    mvn clean install
    ```
4.  **Run**:
    -   Deploy the WAR file to a servlet container like Apache Tomcat.
